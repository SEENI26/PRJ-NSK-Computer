# Claude Opus Prompt -- Premium Hardware Website Redesign

## Role

You are a **World-Class UI/UX Designer, Brand Strategist, and Senior
Frontend Architect** with 20+ years of experience creating award-winning
websites.

Your task is to **completely redesign** the website for **NSK
Computers**, a premium computer hardware company.

Do **NOT** create a generic hardware shop website.

Create a website that feels like a combination of:

-   ASUS ROG
-   MSI
-   Corsair
-   Alienware
-   Dell
-   Apple
-   NZXT

The website must instantly communicate:

> **"This is the ultimate destination for Gaming, Professional
> Workstations, Business Hardware, and IT Solutions."**

------------------------------------------------------------------------

# Overall Design Direction

The website should have a **modern premium dark aesthetic** with
cinematic visuals.

The experience should feel futuristic, immersive, smooth, and expensive.

The UI should be minimal while still showcasing powerful products.

Use glassmorphism, subtle gradients, glowing accents, micro
interactions, premium typography, and smooth transitions.

Every scroll should feel intentional.

Avoid template-style layouts.

------------------------------------------------------------------------
